# Eye textures: where they come from

Every Pokemon eye in this project is an existing, extracted game texture; nothing is hand-painted.  The per-species
outcome is listed in `HANDLING.md` (generated by `pipeline/scripts/check_pokemon_eyes.py --md`).

## 1. Already inside the mesh source (about 120 species)

`Pokemon-3D-api/assets` (https://github.com/Pokemon-3D-api/assets, `models/opt/regular/<dex>.glb`; the repository declares
the MIT licence) ships most Pokemon with their own eye atlases: `pmXXXX_00_Eye1` (a sclera/lid sheet with up to 8
expression cells) plus `Iris1`, an alpha-blended iris/pupil/highlight overlay.  The old pipeline dropped the overlay's
alpha (Godot's cel shader ignores it), which rendered the overlay as an opaque black box: the "visor" look on
Squirtle/Wartortle/Blastoise, Psyduck, Mew, Mr. Mime, Hitmonchan ...  `pipeline/blender/pokemon_eye_bake.py` now
rasterises the iris into the eye atlas through the eye mesh's UVs and removes the overlay, so those textures are used as
authored.  Nothing from this group is copied into this folder; it travels inside the generated
`godot/assets/models/pokemon/*.glb` and their extracted textures.

Caveat on the licence: the MIT header covers the repository's own scripts.  The meshes and textures it serves are
Sketchfab uploads of extracted Nintendo/Game Freak assets, so their real rights status is "fan asset, unclear".

## 2. Copied here: PokeMiners/pogo_assets (Pokemon GO, extracted)

Repo: https://github.com/PokeMiners/pogo_assets      path: `3D Assets/Pokemon/pmXXXX_00_Rig/`
Licence: none published.  The README says all content is the property of The Pokemon Company / Niantic and that PokeMiners
did not create or modify it.  These are Nintendo/Niantic game textures; they are used here for the same reason the rest of
the models are (this repository is a non-commercial fan port that already redistributes extracted models).  If that is a
problem, delete this folder and the `eye_decals` entries of `pipeline/data/pokemon_model_overrides.json`; the pipeline then
falls back to the mesh's own eyes.

| file | upstream path | used for |
|------|---------------|----------|
| `pm0143_00_Face.png` | `3D Assets/Pokemon/pm0143_00_Rig/pm0143_00_Face.png` (unmodified) | Snorlax: the closed-eye strokes are painted over the source model's faint lines (`eye_decals`, `key: dark`) |

Other candidates that were inspected and NOT used because the source meshes already carry a better eye: pm0089 (Muk),
pm0095 (Onix), pm0092 (Gastly), pm0136 (Flareon), pm0025 (Pikachu).  Gastly's face is drawn as flat-colour discs
(`eye_patches`) because its palette atlas cannot hold a painted decal.

## 3. Searched and rejected

* Pokemon eye texture packs on GitHub/Sketchfab marketplaces (VRoid trainer eye packs, MMD eye packs, "CG eye pack"): trainer
  or human eyes, not species eyes, and licences forbid redistribution.
* `PoGo-Devs/PoGo-3D-Assets`, kwsch/pkNX-derived texture sets, Sun/Moon or Sword/Shield extraction repos: not evaluated in
  depth, because PokeMiners/pogo_assets already covers every Gen-1 species with Eye/Face atlases in the same layout as
  the source meshes and none of the others publishes a licence either.
